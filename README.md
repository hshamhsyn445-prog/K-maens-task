# K-Means Clustering

## Description
This project implements the K-Means clustering algorithm using Python and Scikit-learn.

## Features
- Create a dataset.
- Divide data into three clusters.
- Calculate cluster centroids.
- Display cluster labels.
- Visualize the results using Matplotlib.

## Requirements
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Installation
Install the required libraries:

```bash
pip install numpy matplotlib scikit-learn
```

## Run the Project

```bash
python kmeans.py
```
